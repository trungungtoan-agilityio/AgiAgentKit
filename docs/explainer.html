AgiAgentKit, explained

Session Superadvisor runs one Claude Code leader that opens lane sessions in tmux, one per backlog card, each in its own git worktree with its own PR. You talk to the leader only, and approve only merges, production and permissions.

The problem

Running several Claude Code sessions in parallel usually means babysitting each one: feeding it work, approving prompts, noticing when it stalls, and paying for long sessions whose context keeps growing.

  • Attention. Every session wants you. The kit puts one session, the leader, between you and the rest.
  • Collisions. Parallel sessions in one checkout edit the same files. Each lane gets its own worktree and branch.
  • Token sinks. Long subagent runs, whole-suite test runs and strong models on easy work. Hooks and pinned model tiers cut these.
  • No numbers. Metrics hooks record what the main session and each subagent spent, and a scorecard sums it up.

Roles

Owner (you)

Decides product. Approves merges (for example M 12), production and permissions. Does not hand-feed lanes.

Leader

Sizes the backlog S/M/L, writes briefs, opens and unblocks lanes, reports in at most five lines. Does not write large blocks of code.

Lane

One card, one worktree, one PR, then stops. Cannot merge, push to main/master/dev or edit settings.

Brains

lead.md (permissions), decisions.md, directives/, inbox/, config.json. Runtime data in git-ignored .local/.

Card lifecycle

Lane states

StateDetected by
BUSY"esc to interrupt", "ctrl+c to interrupt" or a spinner in the last 15 lines of the pane
IDLENone of the other states: finished, or waiting for input
WAITINGA permission prompt in the last 15 lines ("Do you want to", "Allow this", (y/n)…)
DEADtmux reports the pane dead: Claude Code exited

patrol flags a lane when it is DEAD, WAITING for at least patrol.waiting_min minutes (default 5), or unchanged for at least patrol.stuck_min minutes (default 20, the leader is exempt). Thresholds live in brains/config.json. Patrol only reports.

Model tiers

Five agents, each with its model pinned in its frontmatter. Cheap models read, mid-tier models write, strong models judge. The agent-routing hook rejects calls that pass a model or use general-purpose.

AgentModelUsed for
scoutHaikuRead-only lookups: files, symbols, call sites, summaries
builderSonnetKnown-cause changes across 1–5 files
testerSonnetWriting and fixing tests
debuggerOpusUnknown root cause, or a builder that failed twice
reviewerOpusOne read-only review before a PR

Hooks

Four hooks block, two only record. In auto mode a blocking hook denies with guidance so the agent changes course; in other modes it asks you. owner-guard always denies, because a lane has nobody to ask.

HookStopsThreshold / tune
turn-guardLong builder/tester runs (Read and Grep still pass)Warns at 60 and 90 tool calls, blocks edits from 130. TURN_GUARD_WARN, _WARN2, _DENY, _OFF=1
test-budgetWhole-suite test runs with no file or filterName a file or filter, or prefix FULL_SUITE_OK=1
agent-routingAgent calls with a model, or general-purpose / no typeEvery call
owner-guardIn lanes: gh pr merge, pushes to main/master/dev, writes to .claude/settings*.jsonOnly when KIT_LANE=1
metrics-subagentNothing; logs each subagent runEach SubagentStop
metrics-mainNothing; logs the main session per modelEach Stop. KIT_METRICS_MAIN_MAX_FIRST_BYTES (20 MB)

Metrics and scorecard

The metrics hooks append token counts, never prompt text, to .claude/metrics/events.jsonl in the main checkout, so data survives when a lane's worktree is removed.

  • A subagent row per subagent run: agent, model, tokens, turns, duration.
  • A main row per model per Stop: tokens and ctx_max, the largest context seen. The main session is usually the biggest cost.
plugin/scripts/kit-stats.sh            # writes scorecard.md and scorecard.json
plugin/scripts/token-watch.sh --hours 24

The scorecard shows cost per model, the main session's context percentiles, and a fit score per agent and tier: 1 minus the share of runs that escalated (a builder followed by a debugger, a run that hit the turn cap, or a failed verify). Costs come from a price table; override it with .claude/metrics/pricing.json.

Install

Needs Claude Code, git, tmux and jq on macOS or Linux (Windows through WSL).

Clone this repository, then from the folder that contains it:

claude plugin marketplace add ./AgiAgentKit
claude plugin install agi-agent-kit@agi-agent-kit
AgiAgentKit/bin/superadvisor init /path/to/your-project
AgiAgentKit/bin/superadvisor up /path/to/your-project

Then attach with tmux -L sa attach -t YOUR-PROJECT-LEAD or open it through Remote Control in the Claude app. Full guide: INSTALL.md.

Limits

Hooks are not a security boundary. Without jq they let everything through, quoted text and wrapped commands are not inspected, and owner-guard only applies to lanes. Use branch protection and narrow tokens for real control.
  • Costs in the scorecard are estimates from a price table, not your bill.
  • The leader's merge rules are instructions in brains/lead.md, not enforced by a hook.
  • status reads screen text. A new Claude Code prompt wording can be misread as IDLE.
  • lane close --rm-worktree deletes only branches that git branch --merged lists locally; after a squash merge, remove the worktree yourself.
  • Remote Control needs Claude Code logged in to claude.ai.
  • Skill and hook messages are in Vietnamese; commands and file names are in English.
