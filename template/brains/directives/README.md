# directives/

Chỉ thị của owner dành cho leader: mỗi chỉ thị một file `YYYY-MM-DD-<chủ-đề>.md`.

Một chỉ thị nên có: mục tiêu, giới hạn (không được làm gì), hạn chót nếu có, và tiêu chí "xong".
Leader đọc thư mục này đầu phiên, làm theo, rồi ghi kết quả vào `../decisions.md`. Chỉ thị đã xong thì đổi tên
thêm hậu tố `.done.md` thay vì xoá.
