# inbox/

Hộp thư tới leader: ý tưởng, lỗi gặp phải, yêu cầu của lane gửi lên. Mỗi mục một file ngắn
`YYYY-MM-DD-<chủ-đề>.md` (vài dòng: chuyện gì, ở đâu, mong muốn gì).

Leader phân loại theo cỡ S/M/L trong lượt tuần tra: việc rõ thì thành thẻ + brief, việc mơ hồ thì hỏi owner một câu.
Mục đã xử lý chuyển vào `../decisions.md` (một dòng) rồi xoá khỏi inbox.
